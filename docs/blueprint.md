# **App Name**: BodaEmpire

## Core Features:

- Rider Management: Add, edit, and delete rider information, including name, contact details, and contract terms.
- Payment Tracking: Record and track daily payments from riders, calculate balances, and identify outstanding amounts.
- Alert System: Generate alerts for missed payments and contract expirations to ensure timely action.
- Reporting: Generate weekly/monthly reports on payments, outstanding balances, and other key performance indicators.
- Fleet Growth Calculator: Calculate the time and investment to reach a desired number of bodas and make it a goal to grow a larger company of boda empire. Generative AI tool will provide tips based on your current metrics for improving fleet growth. Based on provided savings use a AI powered tool that makes optimal suggestions for adding bodas over time.
- Offline Access: Enable core functionalities (rider info, payment recording) to work offline using local storage.

## Style Guidelines:

- Primary color: Deep amber gold (#C8860A) for interactive and accent elements. Use for Floating Action Button, slider thumbs and active borders.
- Background color: Warm off-white cream (#F7F3EE). Use as the main page background, providing a neutral and inviting backdrop for content.
- Accent color: Deep forest green (#1A6E3C). This complements the gold, reinforcing themes of financial success.
- Body and headline font: 'Outfit', sans-serif for a modern and readable interface. Note: currently only Google Fonts are supported.
- Use emoji to represent different sections. For example use the motorcycle emoji for the Fleet page.
- Mobile-first layout with a max-width of 480px, centered on larger screens. Employ a consistent card-based design for information display. A floating action button will reside on the fleet tab.
- Subtle animations on button presses and transitions. Animate the growth of the fleet over time. Use `cubic-bezier` easing to produce realistic movements.
